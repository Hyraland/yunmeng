## 操作

WASD 行走，双击 W（按住）或按住 Shift 跑，拖动转头。右上角三个点是菜单：操作说明、晴 / 雾 / 夜、音乐和音效开关、模型来源。N、M、V、B 是夜晚、雾、音效、音乐的快捷键。声音要等第一次点击或按键才会开始（浏览器的规定）。

## 模型

骨骼模型的来源和署名见 [assets/models/SOURCES.md](assets/models/SOURCES.md)。声音和音乐为Claude Opus实时合成。
